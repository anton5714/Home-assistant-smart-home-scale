# Автоматизация: Озвучка веса и ИИ-совет

Что делает:
- При изменении показания `sensor.vesy_weight` (вес) и если вес >= 80 кг,
  воспроизводит через медиаплеер (указан device_id) сначала голосовую сводку,
  затем через 28 секунд отправляет команду с текстом-запросом к ИИ/Алисе и
  получает короткий совет.

Куда положить:
- Положите файл `announce_mi_scale.yaml` в папку `automations/` вашего репозитория
  (или импортируйте через UI: Configuration → Automations → Add Automation → YAML).

Что заменить перед использованием:
- `device_id: d8bb03c0b571d5da161593553246cd7d` → замените на ваш device_id
  (или используйте `entity_id:` с `media_player.your_player`).
- Проверьте имена сенсоров:
  - sensor.vesy_weight
  - sensor.protsent_zhira
  - sensor.massa_zhira
  - sensor.myshechnaia_massa
  - sensor.voda_v_organizme
  - sensor.vistseralnyi_zhir
  Замените, если у вас другие entity_id.
- Не храните токены/секреты в репозитории. Если ваша интеграция использует облачный TTS
  или API Алисы — вставляйте ключи в Secrets/credentials и используйте их в конфиге.

Как активировать:
- Залейте файл в репозиторий и перезагрузите автоматизации:
  Configuration → Server Controls → Reload Automations
  или выполните restart Home Assistant.

Проверка:
- Поставьте на весы и подождите: в логах Home Assistant вы увидите срабатывание
  триггера и воспроизведение/команду к медиаплееру.

Советы / улучшения:
- Чтобы избежать частых повторных срабатываний (когда датчик меряет несколько раз),
  добавьте условие по времени после последнего срабатывания или сравнивайте
  trigger.from_state и trigger.to_state (например, запуск только если вес изменился
  больше чем на 0.1 кг).
- Можно добавить `for: "00:00:03"` в триггер, чтобы убедиться, что показание стабильно.
- Рассмотрите использование `entity_id` вместо `device_id` для простоты.
- Если хотите — могу добавить проверку дубликатов (debounce) и версию
  с использованием `variables:` для уменьшения повторяющегося кода.
