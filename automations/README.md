# Автоматизация: Озвучка веса и ИИ-совет

Описание
- При изменении показания `sensor.vesy_weight` (вес) и если вес >= 80 кг,
  воспроизводит через медиаплеер (указан entity_id) голосовую сводку,
  затем через 28 секунд отправляет команду с текстом-запросом к ИИ/Алисе и
  получает короткий совет.

Куда положить
- Положите файл `announce_mi_scale.yaml` в папку `automations/` вашего конфигурационного репозитория
  (или импортируйте через UI: Configuration → Automations → Add Automation → YAML).

Что заменить перед использованием
- Замените `device_id`/`entity_id` на ваш медиаплеер (например, `media_player.yandex_station`).
- Проверьте имена сенсоров и при необходимости замените на ваши:
  - sensor.vesy_weight
  - sensor.protsent_zhira
  - sensor.massa_zhira
  - sensor.myshechnaia_massa
  - sensor.voda_v_organizme
  - sensor.vistseralnyi_zhir
- Не храните токены/секреты в репозитории. Если используется облачный TTS или внешний API — используйте `secrets.yaml`.

Как активировать
- Разместите YAML в папке `automations/` и перезагрузите автоматизации:
  Configuration → Server Controls → Reload Automations
  или перезапустите Home Assistant.

Проверка
- Поставьте на весы и подождите: в логах Home Assistant вы увидите срабатывание
  триггера и воспроизведение на медиаплеере.

Рекомендации по стабильности
- Чтобы избежать частых повторных срабатываний, добавьте условие по времени после последнего срабатывания
  или сравнивайте `trigger.from_state` и `trigger.to_state` (например, запуск только если вес изменился
  более чем на 0.1 кг).
- Рекомендуется использовать `for: "00:00:03"` в триггере, чтобы убедиться, что показание стабильно.
- Рекомендуется использовать `entity_id` вместо `device_id` для простоты конфигурации.
