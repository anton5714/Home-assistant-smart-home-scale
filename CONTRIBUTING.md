# CONTRIBUTING

Спасибо за интерес к репозиторию! Вот краткие рекомендации, как внести вклад.

1. Формат вкладов
- Fork → создайте ветку с именем `feat/<имя>` или `fix/<описание>`.
- Сделайте изменения и отправьте Pull Request с описанием изменений.

2. Commit messages
- Используйте префиксы: `feat:`, `fix:`, `docs:`, `chore:`, `refactor:`.
- Кратко опишите, что и почему было сделано.

3. Issues
- Перед тем как создавать issue, проверьте, нет ли уже похожей темы.
- Включите шаги воспроизведения и логи, если проблема связана с ошибкой.

4. Code style
- YAML: используйте 2 пробела отступа.
- Комментарии: поясняйте нестандартные формулы и магические числа.

5. Безопасность
- Не добавляйте секреты в репозиторий. Для тестов используйте placeholders или `!secret`.

Если нужна помощь с PR — напишите в issue и я помогу провести ревью.
