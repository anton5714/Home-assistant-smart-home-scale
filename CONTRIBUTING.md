# Contributing

Спасибо за вклад в проект.

## Перед изменением

1. Убедитесь, что изменение относится к Xiaomi Mi Scale / Mi Scale 2, ESPHome или Home Assistant.
2. Не добавляйте реальные Wi-Fi, API, OTA или другие секреты.
3. Не добавляйте персональные данные и реальные MAC-адреса в примеры без необходимости.

## Проверка ESPHome

Перед commit рекомендуется проверить конфигурацию локально:

```bash
esphome config esphome/esp-bt.yaml
```

Если конфигурация использует `!secret`, запускайте проверку из каталога с локальным `secrets.yaml`, который не должен попадать в Git.

## Стиль

- YAML — 2 пробела для вложенности.
- Имена сущностей и файлов — понятные и стабильные.
- Комментарии объясняют **почему**, а не повторяют очевидное.
- Не используйте приблизительные формулы состава тела без явного предупреждения о точности.

## Pull request

В PR укажите:

- что изменилось;
- на какой модели Mi Scale проверено;
- версию ESPHome/Home Assistant, если изменение зависит от версии;
- результат проверки конфигурации.
