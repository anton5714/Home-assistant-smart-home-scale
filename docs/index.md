# GitHub Pages

Чтобы опубликовать документацию как сайт:
1. Перейдите в Settings → Pages.
2. В разделе Source выберите branch: `main` и folder: `/docs`.
3. Нажмите Save — сайт станет доступен через github.io (несколько минут).

Рекомендация: используйте MkDocs/Material для красивой документации — я могу подготовить mkdocs.yml и шаблон при необходимости.
